## Objective

Introduce a scheduler responsible for delaying retry execution according to the configured BackoffStrategy.

This task composes the previously implemented abstractions without changing their responsibilities.

## Context

Previous slices introduced:

RetryPolicy → determines if another attempt should occur.
BackoffStrategy → determines how long to wait.

This slice introduces the final component responsible for executing retries after the computed delay.

## Scope
In Scope

Introduce:

platform
└── messaging
└── retry
├── RetryScheduler
└── ScheduledRetryScheduler

The scheduler should expose a transport-agnostic API similar to:

public interface RetryScheduler {

    <T> CompletionStage<T> schedule(
        Supplier<CompletionStage<T>> action,
        BackoffDelay delay
    );

}

The default implementation should:

use ScheduledExecutorService
schedule asynchronous execution
never block the calling thread
never call Thread.sleep()
